# Обзор

Continuum — UI-фреймворк на **классическом FRP** — дискретной ветви
функционального реактивного программирования (в духе Sodium), применённой к
DOM.

## Что это

Всё происходящее в интерфейсе моделируют две абстракции:

- **`Behavior<A>`** — значение, существующее в каждый момент: текст поля,
  текущий пользователь, URL.
- **`Event<A>`** — дискретные вхождения: клики, ответы, тики.

Компоненты — обычные функции, выполняющиеся **один раз**. Они строят
FRP-сеть и подключённый к ней DOM; дальше обновления — это значения,
протекающие по сети в конкретные текстовые узлы и атрибуты. Нет ре-рендеров,
нет виртуального DOM, нет отслеживания зависимостей в рантайме — граф
зависимостей и _есть_ написанная вами программа.

```tsx
import { newEvent } from "@continuum-js/frp";
import { mount } from "@continuum-js/dom";

function Counter() {
  const [clicks, fire] = newEvent<MouseEvent>();
  const count = clicks.accum(0, (_e, n) => n + 1);
  return <button onClick={fire}>count: {count}</button>;
}

mount(document.getElementById("app")!, () => <Counter />);
```

## Чем отличается

**Транзакции.** Каждое обновление — атомарный момент логического времени.
Производные значения никогда не видят полуобновлённое состояние («глитчи») —
не потому что обновления склеены ради скорости, а потому что одновременность
— часть модели.

**Честная асинхронность.** IO входит в сеть данными: ошибка — ветка
`Result`, загрузка — значение. Гонка ответов решена один раз в библиотеке, а
не `cancelled`-флажком в каждом эффекте.

**Маленький.** Весь стек — ядро, DOM-рендерер, std-утилиты, роутер — меньше
8 kB brotli, с жёсткими бюджетами размера в CI.

## Пакеты

| Пакет                  | Что внутри                                                                   | Размер (brotli) |
| ---------------------- | ---------------------------------------------------------------------------- | --------------- |
| `@continuum-js/frp`    | Behaviors, Events, транзакции, `perform`, непрерывное время                  | ~1.8 kB         |
| `@continuum-js/dom`    | JSX-рендерер, `dyn`/`Show`/`Each`, владение, контекст, `onMount`/`onCleanup` | ~3.7 kB с frp   |
| `@continuum-js/std`    | `debounce`/`throttle`/`interval`, `resource`, `distinctB`, …                 | ~2 kB с frp     |
| `@continuum-js/router` | URL как Behavior, вложенные роуты, guards, `lazy`-сплиттинг                  | ~3.9 kB со всем |
| `@continuum-js/test`   | `render`/`fire`/`type`/`flush` для vitest                                    | только dev      |
