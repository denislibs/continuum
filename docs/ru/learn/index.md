# Учитесь на практике

Проходите короткие упражнения с проверкой. Пишете код справа, жмёте **Check**,
и переходите дальше, когда загорается зелёный. Откройте вкладку **Compiled** —
увидите, во что превращается ваш JSX: никаких ре-рендеров, только точечные
обновления DOM.
