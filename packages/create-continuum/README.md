# create-continuum-js

Scaffold a [Continuum](https://denislibs.github.io/continuum/) app:

```bash
npm create continuum-js@latest my-app
cd my-app && npm i && npm run dev
```

The template ships Vite + TypeScript, the Continuum compiler plugin, ESLint with `@continuum-js/eslint-plugin`, Prettier, a working test setup (`@continuum-js/test` + vitest) and an `AGENTS.md` so AI assistants know the house rules.
